# prototype/

Throwaway spikes. **Never ships.** Code that explores a question — a graph
rendering approach, an NVD fetch, a CWE import — and is then thrown away or
promoted deliberately into a real module once a `DEC-*` is settled.

Nothing here is on the critical path. If a spike is worth keeping, it earns a
task in `project/BACKLOG-0001.md` and a home outside `prototype/`.
