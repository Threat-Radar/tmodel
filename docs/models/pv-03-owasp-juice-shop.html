OWASP Juice Shop

A web shop for fruit juice with accounts, a basket, orders, a search page and an administration section, built to be insecure for training. Modeled at v20.4.0, run locally (Node.js, or its Docker image).

Example data. This model was drafted by AI from published sources about a real product, to exercise tmodel's object model. It is not a verified security assessment of the product it names. No human review is recorded in it, so every threat and attack path in it is a hypothesis.
