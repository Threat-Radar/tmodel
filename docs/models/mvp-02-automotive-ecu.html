Composite vector per ADR-0006/DEC-003: feasibility + S/F/O/P impact + mitigation-status + derived risk, shown with its inputs. Safety-dominated. Computed WITHOUT an Environment parameter (§8 MVP). Impact (15.5), rated for the road users harmed, with the Annex F examples as RPT-0007 §3.1 paraphrases them. Safety severe: a brake command no one gave, at speed, can cause fatal or life-threatening injuries with survival uncertain, which is ISO 26262-3 class S3 (RQ-15-06). Financial major: crash repair, recovery and time off the road are serious costs that the road user can recover from. Operational severe: braking, a core vehicle function, behaves unexpectedly, and the vehicle cannot be trusted to drive until the unit is isolated or patched. Privacy negligible: this damage scenario exposes no personal information; data that the same diagnostic access could read would be a separate damage scenario. Feasibility (15.7): High, by attack vector (RC-15-14, G.4), as rated on the attack path. Risk values (15.8): one per impact category (RQ-15-15, NOTE 1), read from the example risk matrix in Annex H (Table H.8). Treatment decision (15.9): reduce (RQ-15-17). Diagnostic authentication is in place (complete) and the domain gateway filter is being rolled out (in progress); each is stated as a requirement. The score's mitigation status stays in progress until the filter is complete.
