Example threat models

Worked examples of what tmodel produces: each page is a threat-model report, in the order a TARA reads it, with every threat and attack path marked with its review status.

Example data. These models were written to exercise tmodel's object model; none of them is a security assessment. The proposal examples were drafted by AI from published write-ups of real automotive attacks and name the real products. AI-proposed threats and paths are hypotheses until a human reviewer accepts them.
