Overview

A stub: not read in full. An Informational RFC that retires the MD4 message digest algorithm and moves RFC 1320, which specified it, to Historic status. It reviews the attacks on MD4's collision, preimage and second preimage resistance and on HMAC-MD4, and lists the RFCs that had specified the use of MD4. Cited by tmodel RPT-0004 (tmodel#38): the IETF's move of MD4 to Historic status, cited in RPT-0004 section 1.2 on SPDX's hash algorithm list.
