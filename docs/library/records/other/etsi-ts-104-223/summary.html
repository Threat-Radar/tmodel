Overview

The first publication of what became ETSI EN 304 223. The EN's History table lists V1.1.1 (April 2025) as "Publication as ETSI TS 104 223", then the EN approval procedure, then EN V2.1.1 (December 2025). The UK government's Code of Practice page (pinned in uk-ai-cyber-security-code-2025, published 31 January 2025) says the UK "plan to submit the Code and Implementation Guide in ETSI"; this TS followed in April 2025.
