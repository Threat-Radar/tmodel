Overview

Asks whether an LLM API gateway (OpenRouter) breaks the prompt-cache isolation that inference providers give each account. The paper detects cache hits two ways, from timing differences and from the cached-token counts some providers report. It concludes that OpenRouter's "use of shared organizational credentials enables cross-account cache sharing that would not occur when accessing providers directly": all three providers tested showed cache sharing in OpenRouter's default mode, and isolated caches when called directly or through OpenRouter's bring-your-own-key mode (§VIII). Its recommendation is per-user cache isolation at the gateway.
