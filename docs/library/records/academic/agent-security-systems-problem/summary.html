Overview

A short position paper by the authors of systems-security-agentic-computing, building on it. Per RPT-0009 §2.6: treat the model that powers an agent as an untrusted component and enforce security invariants at the system level, through provable separation of instructions and data, least-privilege sandboxing with verifiable policy generation, and information-flow control. It argues that stacking ML guard models is not real defense in depth, because they share failure modes.
