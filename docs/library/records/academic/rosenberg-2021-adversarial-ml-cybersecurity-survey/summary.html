Overview

The survey argues that security is the domain where adversarial machine learning matters most, because malware authors and phishers are real adversaries, yet it is where end-to-end attacks are hardest: a perturbed sample must keep working, features such as API calls are discrete, and executables are variable-length and described by several feature types at once (§1, §2). It proposes a taxonomy of seven attack characteristics in four phases: the threat model (attacker knowledge, training-set access), the attack type (goal, targeted phase, targeting), the perturbed features, and the output, either a feature vector or a working sample (§4, Figure 2). It then reviews published attacks on malware, phishing-URL, DGA, intrusion, spam, industrial-control and biometric classifiers, marking each for realistic attacker knowledge, end-to-end output, effectiveness and representative data and features (§5, Tables 1-7). It concludes that feature-vector attacks are easy but real-life attacks on commercial products remain hard, and it names gaps that other domains had already filled: backdoor attacks, resource-exhaustion attacks, model extraction and side channels, and exploits of the ML frameworks themselves (§7, §8).

Limits

  • Coverage ends in 2020. It predates LLM-based security tools, so attacks such as prompt injection against AI-driven security tooling (AIT-130) are outside it.
  • The feasibility marks are the authors' judgement. Each attack gets five yes or no marks (Tables 1-7). Effective means a success rate over 90% as each paper reports it, and whether a dataset or feature set is representative is the authors' call, not a measurement.
  • Most intrusion-detection and industrial-control attacks reviewed are not realizable. Fewer than 10% of them produce a working network stream or sensor trace (§7.5).
  • The gaps are stated as of 2020. That no backdoor or model-extraction attack had been applied to security classifiers (§7.1, §7.3) describes the literature reviewed, not the present.
  • Defenses get a short section (§6) with no comparative evaluation.
  • The in-the-wild evidence is one report. The claim that such attacks had already been used against a commercial static-analysis classifier rests on Skylight Cyber's 2019 Cylance bypass (§1, §7.6).
  • Preprint, not the version of record. arXiv v3 (57 pages) was read in full apart from the model background in Appendix A, which was skimmed. The 36-page ACM version was not compared.
