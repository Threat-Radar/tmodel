Overview

Model hubs such as Hugging Face let anyone publish models and datasets, and loading them can run the publisher's code: pickle-based model files execute code when they are deserialized, and the datasets library ran a dataset's loading script by default (§2.2). The paper calls this malicious code poisoning and, by its own account, gives the first systematic study of it: a threat model, a taxonomy of 15 model formats by whether they can carry code (Table 2), and the root cause, serialization formats that instantiate arbitrary objects (§3). Its pipeline, MalHug, extracts dataset scripts, disassembles pickles and Keras Lambda layers without running them, and applies taint analysis and YARA rules to the extracted code (§4). Run for more than three months on Ant Group's mirror of Hugging Face, it found 91 malicious models (76 pickle variants, 15 Keras Lambda layers) and 9 malicious dataset loading scripts among 705,991 models and 176,386 datasets, with reverse shells, browser credential theft and system reconnaissance among the payloads (§5). Over 55% of the models use pickle-based serialization (§5.2).

Limits

  • A floor, not a rate. One hub, one enterprise mirror, three months, and repositories with restricted access excluded (§5.1, §6).
  • Proofs of concept are in the count. The manual review judged some flagged code to be harmless researcher demonstrations, and Figure 4 keeps them as a category beside remote control and information theft. The text does not give the split.
  • Static analysis with a hand-made list. The unsafe-API list comes from Pyre, Semgrep and Pysa rules and may miss exploits. No obfuscated model was seen, but the authors cannot rule one out (§6). TensorFlow models with risky operators are only flagged, so some may be false positives (§4.2, §6).
  • No precision or recall. There is no ground-truth set. The comparison with Fickling, ModelScan and the rest is a feature table (Table 6), not a measured detection rate.
  • The format verdicts date from 2024 and cover code execution on load. Table 2 rates GGUF and ONNX as not vulnerable, as far as was known then. A GGUF file still carries a chat template, a Jinja2 program that runs on every inference call, and RPT-0014 records a 2025 demonstration of backdoors planted that way (INC-094, AIT-031).
  • The dataset-script vector has narrowed. Hugging Face's datasets 4.0.0 (2025-07-09) removed loading scripts altogether. Environments pinned to older versions are not covered by that change.
  • Preprint, not the version of record. arXiv v1 was read; the ACM version was not compared.
