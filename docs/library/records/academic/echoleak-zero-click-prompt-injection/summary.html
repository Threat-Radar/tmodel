Overview

A case study of EchoLeak (CVE-2025-32711) by researchers who did not find it: "researchers at Aim Security disclosed EchoLeak", and the finders' disclosure is aim-labs-echoleak-disclosure. Per RPT-0009 §5: one email carried hidden instructions; retrieval later pulled it into Copilot's context; Copilot put the user's data into a reference-style image link; and the client fetched it through an allow-listed Teams service to the attacker's server. The abstract names four steps in the chain: "evading Microsoft's XPIA (Cross Prompt Injection Attempt) classifier, circumventing link redaction with reference-style Markdown, exploiting auto-fetched images, and abusing a Microsoft Teams proxy allowed by the content security policy". Its threat model lists three defenses that were in place: the XPIA classifier, output filtering that redacts external links, and the browser content security policy. The paper recommends prompt partitioning, filtering every link and image, and strict content security policies.
