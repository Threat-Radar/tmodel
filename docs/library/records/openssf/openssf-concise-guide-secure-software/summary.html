Overview

The guide is a one-page list of 29 numbered imperatives "for all software developers for secure software development, building, and distribution". It covers:

  • account security: MFA for privileged developers;
  • learning secure development;
  • tooling in CI;
  • dependency hygiene: evaluate before adopting, use package managers, monitor vulnerabilities in direct and indirect dependencies, update after a ~3-day cooldown;
  • no secrets in repositories, and review before accepting changes;
  • vulnerability reporting, advisories and CVEs;
  • signed releases, SBOMs and SLSA levels;
  • third-party audits, succession, memory-safe languages;
  • source packages that contain only VCS content (the xz lesson), and loading web assets only from your own domains.

Several items delegate to heavier frameworks: the OpenSSF Best Practices badge, Scorecard, SLSA, the CNCF Supply Chain Best Practices, ASVS and SAFECode. That makes the guide a small index of the SDL ecosystem as OpenSSF sees it.
