Overview

The UK's "voluntary Code of Practice which will be used to help create a global standard in the European Telecommunication Standards Institute (ETSI) that sets baseline security requirements" (pinned page). It follows DSIT's Call for Views (15 May to 9 August 2024), builds on the NCSC's guidelines for secure AI development, and comes with a separate implementation guide. The page says "The UK government plan to submit the Code and Implementation Guide in ETSI so that the future standard is accompanied by a guide", and that the government will update both "to mirror the future ETSI global standard and guide". ETSI TS 104 223 (April 2025) and TR 104 128 (May 2025) followed. The pinned page does not itself say they are based on the Code.
