Overview

A stub: not read in full. UN Regulation No. 156 sets uniform provisions for the type approval of vehicles that permit software updates, covering the manufacturer's software update management system and the requirements on software updates, including the RX Software Identification Number (RXSWIN) and the register of software versions and integrity validation data behind it. This record holds the original version, in force since 22 January 2021 and published by UNECE in March 2021. Cited by tmodel RPT-0004 (tmodel#38): the RXSWIN definition and duties (conditional on a vehicle type using RXSWIN) and the software register with integrity validation data, behind candidate rule R-ID-5.
