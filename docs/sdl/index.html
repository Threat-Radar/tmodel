tmodel SDL: tmodel desktop app (macOS)

Example data, draft. Built from an example SDL model, not from approved project records. Every selection on this page is a proposal until a human review accepts it; status was drafted by an AI agent from repository evidence and has not been reviewed. Not a conformance claim. Licensed standards appear as ids only.

Local threat-modeling app: a Tauri + TypeScript shell with a Python engine sidecar that serves a loopback-only API (127.0.0.1:47811). Distributed as an ad-hoc-signed .dmg from GitHub Releases (ADR-0003, PLAN-0002).

      Open gaps

      • Release sign-off: Tag builds become draft releases a human publishes; there is no recorded gate decision or checklist yet.
      • Coordinated vulnerability disclosure: No SECURITY.md and GitHub private vulnerability reporting is off.
      • Watch released dependencies for vulnerabilities: Dependabot alerts are on; security updates and secret scanning are off; no triage owner.
      • Developer ID signing and Apple notarization: Not done; the Apple secrets are not set, so Gatekeeper warns on every install.
      • Hermetic, hash-pinned build inputs (SLSA L3 gaps): Floating stable Rust, shared caches and unhashed pip installs remain; provenance is not from an isolated workflow.
