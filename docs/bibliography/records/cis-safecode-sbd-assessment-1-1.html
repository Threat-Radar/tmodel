Overview

An assessment guide for software security practices, built on the NIST SSDF and organised as six considerations. It maps to the CIS Critical Security Controls, to development groups, roles and artifacts, and v1.1 adds AI coverage. SAFECode describes it as underlying a new ETSI standard and "consistent in content with" ETSI TS 104 219 — use the etsi-ts-104-219 record (full FX-1) for requirement content.
