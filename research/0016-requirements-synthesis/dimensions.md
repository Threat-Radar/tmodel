# Sweep dimensions

Six clusters, each extracting: *testable capability → acceptance → class (MVP / post-MVP /
aspiration) → maps_to (existing `R-`/`A-`/`T-` or NEW) → target doc*.

| axis | reports | focus |
|---|---|---|
| A — methodology / competitive | RPT-0001, 0002, 0003 | attack structure, frameworks, product features |
| B — composition / identity | RPT-0004 | SBOM/HBOM, identity, relationships, radar contract |
| C — schema / KG | RPT-0005, 0011, 0015 | schema quality, provenance, grounding, interchange |
| D — UI / display / platform | RPT-0006, 0012 | interaction, display budgets, accessibility, packaging |
| E — risk / TARA / SDL | RPT-0007, 0013 | TARA workflow, risk combiner, SDL/conformance |
| F — AI threats | RPT-0009, 0014 | AI taxonomy, agent capabilities, AI-safety of tmodel itself |

RPT-0001, 0005, 0012 are `pending` skeletons (see report §5).
