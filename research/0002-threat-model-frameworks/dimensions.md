# RPT-0002 — dimensions

The columns of the comparison table; every framework section answers each.

1. **What it models** — assets, data flows, attackers, privacy, business risk?
2. **Notation** — diagram (DFD), tree, checklist, process stages, matrix.
3. **Attack path / steps** — does it represent multi-step attacks, and how
   (tree nodes, kill-chain phases, ATT&CK techniques, none)? *Most important
   column for #15.*
4. **Manual vs automatable** — can a tool derive threats, or is it expert workshop work?
5. **Tooling** — tools that implement it (links; coordinate with #7).
6. **Maturity / adoption** — age, who uses it, still maintained?
7. **Strengths / limits.**

**Snowball rule.** Mine each strong source's references for more frameworks and
sources; log them in `searches.md`.
